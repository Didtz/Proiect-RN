🤖 MACHINE LEARNING

Model Architecture:
  - Base: MobileNetV2 (ImageNet weights)
  - Custom Layers: Dense(256) → Dense(128) → Dense(5)
  - Training: Transfer learning with fine-tuning
  - Input: 224×224 RGB images
  - Output: 5 plant classes + confidence

Training Features:
  ✓ Data augmentation (rotation, zoom, flip, shift)
  ✓ Early stopping (prevent overfitting)
  ✓ Learning rate scheduling
  ✓ Model checkpointing
  ✓ Dropout regularization
  ✓ Synthetic data generation

Performance:
  - Model size: ~100 MB
  - Inference time: <1 second
  - Accuracy: Depends on training data
  - Training time: 5-15 minutes

🔌 API ENDPOINTS

POST /api/predict
  - Upload image file
  - Returns: plant name, confidence, care info

GET /api/plants
  - Get all plants in database
  - Returns: JSON array

GET /api/plant/<name>
  - Get specific plant details
  - Returns: plant information

GET /api/model/status
  - Check if model is trained
  - Returns: status, classes, metadata
